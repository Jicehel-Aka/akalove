AKA-Love — simulateur PC (sans fenetre)

Execute un jeu Love2D avec le meme runtime que la console (Lua 5.1, love.*), horloge virtuelle
deterministe, et ecrit une capture de l'ecran 320x240 au format PPM.

  akalove-sim games/hello --frames 60 --shot hello.ppm
  akalove-sim games/runner --frames 300 --shot runner.ppm --press a:10:12

Options : --frames N  --shot f.ppm  --shot-frame K  --press bouton:de:a  --save dossier
          --watchdog-ms N  --realtime
Boutons : up down left right a b c d l1 r1 menu


AKA-Love — simulateur PC AVEC fenetre + son (akalove-play, SDL2)

Meme runtime, mais affiche une fenetre 640x480 (ecran 320x240 BGR565 x2) et joue les
4 voies audio. Concu pour JOUER et pour etre lance par AKA-IDE (bouton Tester).

Lancer un seul jeu :
  akalove-play "chemin/vers/le/jeu"     (dossier contenant main.lua / conf.lua)

Lancer le MENU de jeux (comme sur la console) pour changer de jeu a la volee :
  akalove-play --home "dossier_AKA_Love" --menu
  (dossier_AKA_Love contient games/<jeux> ; depuis le paquet de la release : --home . --menu)
  Dans le menu : Haut/Bas choisir, A (Espace) lancer. Pendant une partie, le bouton
  MENU (touche M) revient au menu de selection. Echap (ou fermer la fenetre) quitte.

Le jeu tourne jusqu'a la fermeture de la fenetre (ou Echap) ; --frames est ignore ici.
Sous Windows, garder SDL2.dll a cote de akalove-play.exe.

Commandes clavier :
  fleches        = D-Pad (haut/bas/gauche/droite)
  I J K L        = stick analogique (haut/gauche/bas/droite)
  Espace/Entree  = A      X = B      C = C      V = D
  Maj gauche     = L1     Maj droite = R1       M = MENU (retour au menu de jeux)
  Echap          = quitter le simulateur
